# KANGAYATH WEB API

FastAPI Backend for KANGAYATH digital showroom, physical store status management, and garment catalog discovery.

## Features
- **FastAPI 0.115+** with async SQLAlchemy 2.0 and PostgreSQL (asyncpg)
- **Alembic** database migrations
- **Pydantic v2** validation and settings management
- **Real-Time Store Status** calculation with Asia/Kolkata timezone support
- **Product Catalog** management with lifecycle states (DRAFT, PUBLISHED, ARCHIVED)
